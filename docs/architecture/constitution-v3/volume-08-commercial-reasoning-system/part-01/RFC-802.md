# RFC-802 — Evidence Weighted Reasoning

Reasoning quality depends on evidence.

Agent authority never overrides evidence quality.

Priority:

```text
Repeated Marketplace Validation

↓

Experimental Knowledge

↓

Benchmark

↓

Marketplace Analytics

↓

Human Expert Review

↓

Commercial Genome

↓

Adaptive Parameters

↓

Agent Heuristics
```

Evidence determines proposal strength.
