# RFC-2202 — Genome Mutation Policy

Commercial Genome MAY be changed only by Learning Engine through approved lifecycle events.

Allowed mutation events:

```yaml
AllowedGenomeEvents:
  - GenomeObjectCreated
  - GenomeObjectPromoted
  - GenomeObjectDeprecated
  - GenomeObjectArchived
  - ConfidenceUpdated
  - ApplicabilityUpdated
  - ConflictResolved
```

Direct file or database mutation is prohibited.
