# SPEC-2203 — Confidence Model

Every Genome object SHALL have confidence.

```yaml
Confidence:

  value:
    type: number
    minimum: 0
    maximum: 1

  source_breakdown:
    theoretical: number
    experiment: number
    benchmark: number
    marketplace: number
    human_review: number
    learning: number

  last_updated:
    type: ISODateTime

  confidence_history:
    required: true
```

Confidence SHALL be explainable.

Confidence SHALL NOT be produced by LLM probability.
