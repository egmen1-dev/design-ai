# DAOS Cognitive Architecture

## Purpose

The runtime specification defines how DAOS executes.

This document defines how DAOS thinks.

This is the highest abstraction level of the platform.
Everything below this document is an implementation of the cognitive model.

Commercial Genome
Knowledge Resolution
DecisionGraph
SceneGraph
Learning
Research

All are consequences of this document.

This document SHALL NOT describe software.
It SHALL describe intelligence.

## Core Principle

DAOS SHALL behave as a Commercial Intelligence System.

The purpose of DAOS is NOT to:

- generate images
- write prompts
- optimize layouts

The purpose of DAOS is to:

1. Understand a commercial problem.
2. Reason about possible solutions.
3. Select the best strategy.
4. Transform the strategy into visual execution.
5. Learn from measurable evidence.
6. Improve future reasoning.

Everything else is implementation detail.

## Cognitive Cycle

DAOS SHALL think using one canonical loop.

Observe

↓

Understand

↓

Reason

↓

Predict

↓

Decide

↓

Plan

↓

Execute

↓

Evaluate

↓

Learn

↓

Research

↓

Evolve

This cycle SHALL become the foundation of every runtime.

## Cognitive Phases

### Observe
Question

What exists?

Input

- Generation Request
- Historical Knowledge
- Marketplace context
- Product identity
- Brand context

Output

- Observed Reality

### Understand
Question

What does this mean?

Output

- Commercial Understanding

Understanding SHALL cover:

- Product
- Buyer
- Marketplace
- Competition
- Brand
- Context
- Constraints
- Goals

Understanding is not yet decision making.

### Reason
Question

What strategies are possible?

Output

- Commercial Hypotheses

Reasoning SHALL produce multiple possible strategies.

No strategy is accepted automatically.

### Predict
Question

What is likely to happen?

Predictions SHALL include confidence.

The system SHALL estimate at least:

- CTR likelihood
- attention allocation likelihood
- readability likelihood
- commercial clarity likelihood
- competitive differentiation likelihood
- risk likelihood

Output

- Predictions with confidence

### Decide
Question

Which strategy is best?

Output

- Commercial Strategy

Decision SHALL maximize expected commercial value under uncertainty.

### Plan
Question

How is the strategy expressed visually?

Output

- Visual Plan

The plan SHALL remain independent of rendering technology.

### Execute
Question

Can the plan be realized?

Output

- Rendered Candidate

Execution SHALL never change strategy.

### Evaluate
Question

Did reality match prediction?

Output

- Evaluation Report

Prediction error SHALL be measured.

### Learn
Question

What should become reusable knowledge?

Output

- Learning Event

Learning SHALL update confidence, never silently rewrite production knowledge.

### Research
Question

What is still unknown?

Output

- Research Proposal

Research SHALL produce new experiments, not immediate rules.

### Evolve
Question

Should the platform change?

Output

- Genome Proposal
- Research Proposal
- Architecture Proposal

No evolution SHALL bypass governance.

## Cognitive Memory

DAOS SHALL maintain distinct memories with one owner each.

Working Memory

- Current generation only.
- Contains GenerationContext.

Short-term Memory

- Current runtime decisions.
- Contains DecisionGraph.

Operational Memory

- ResolvedKnowledgeSet used to perform reasoning.

Long-term Memory

- Commercial Genome.

Research Memory

- Experimental Knowledge Base.
- Benchmark history.

Reflection Memory

- Architecture decisions.

Each memory SHALL have one owner.

## Cognitive Rules

DAOS SHALL separate the following categories and SHALL never mix them:

- Facts
- Knowledge
- Hypotheses
- Predictions
- Decisions
- Plans
- Evidence
- Learning
- Research

Separating these categories prevents accidental circular reasoning.

## Cognitive Invariants

DAOS SHALL always know:

- What it knows.
- What it does not know.
- Why it made a decision.
- What evidence supported it.
- What alternatives were rejected.
- What uncertainty remained.

## Cognitive Failure Model

Failures are classified as:

- Observation Failure
- Knowledge Failure
- Reasoning Failure
- Prediction Failure
- Decision Failure
- Planning Failure
- Execution Failure
- Evaluation Failure
- Learning Failure
- Research Failure

Each failure SHALL produce diagnostics.
Failures SHALL become learning opportunities.

## Final Principle

DAOS is not an AI that creates images.
DAOS is an AI that makes commercial decisions.

Images are evidence of those decisions.

Commercial intelligence is the product.
Rendering is only one implementation of that product.
