# SPEC-313 — Decision Categories

DecisionGraph consists of specialized decision nodes.

```yaml
DecisionNodes:

  SceneDecision

  EnvironmentDecision

  CompositionDecision

  HeroDecision

  TypographyDecision

  OverlayDecision

  LightingDecision

  CameraDecision

  MaterialsDecision

  ColorDecision

  CTAEvaluation
```

Each node owns only one commercial decision.
