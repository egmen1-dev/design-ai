# RFC-300 — Core Domain Model

The Core Domain Model defines every persistent business entity inside DAOS.

The domain model is the permanent foundation of the operating system.

Engines may evolve.

Algorithms may change.

Providers may be replaced.

Domain entities must remain stable.

Every subsystem inside DAOS operates exclusively on Domain Objects.

No subsystem may introduce undocumented entities.

No subsystem may modify entities it does not own.
