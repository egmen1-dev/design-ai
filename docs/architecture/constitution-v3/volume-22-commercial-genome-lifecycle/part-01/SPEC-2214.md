# SPEC-2214 — Genome Diagnostics

Every generation SHALL record:

```yaml
GenomeDiagnostics:

  genome_version:

  consumed_laws:

  consumed_rules:

  consumed_category_rules:

  ignored_rules:

  ignored_reason:

  conflicts_detected:

  confidence_summary:

  experimental_rules_used:
```

Diagnostics SHALL be included in Debug Bundle.
