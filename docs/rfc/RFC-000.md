## Mission

Design AI Operating System (DAOS) is **not** an image generator.

DAOS is a **commercial design intelligence operating system**.

The purpose of DAOS is to make better commercial design decisions than a human designer, while remaining **explainable**, **reproducible**, and **continuously improving**.

Rendering is only one implementation detail.

## Vision

DAOS separates intelligence from implementation.

- Knowledge is separated from rendering
- Commercial strategy is separated from visual execution
- Architecture is separated from code
- Prompt is separated from reasoning
- Providers are interchangeable

## Primary Goals

### GOAL 01

Generate marketplace creatives with **agency-level quality**.

### GOAL 02

Continuously improve from **accumulated knowledge**.

### GOAL 03

Remain **provider independent**.

### GOAL 04

Remain **architecture driven**.

### GOAL 05

**Explain every decision.**

### GOAL 06

Scale without **architectural degradation**.

## Non Goals

DAOS is **not**:

- a prompt library
- a template engine
- a collection of scripts
- a Flux wrapper
- a GPT wrapper
- a rendering engine

## Core Principles

- Architecture First
- Knowledge First
- Commercial First
- Specification First
- Provider Independent
- Runtime Driven
- Immutable State
- Continuous Learning
- Explainable Decisions

## Design Philosophy

Every generation is treated as a **business decision**.

Every image must justify its existence.

Every visual element must support conversion.

Every decision must have evidence.

## Success Metrics

- Commercial Score
- CTR Prediction
- Marketplace Fit
- Professional Score
- Readability
- Visual Hierarchy
- Architecture Score
- Learning Quality

## Long Term Vision

DAOS evolves into a **universal commercial design operating system** capable of supporting multiple marketplaces, multiple providers, multiple design domains, and autonomous improvement through accumulated knowledge.
