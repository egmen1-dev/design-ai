# SPEC-210 — Experimental Knowledge Base

Research Engine owns Experimental Knowledge Base.

```yaml
ExperimentalKnowledgeBase:

  versions:

    v1.0

    v1.1

    v1.2

    v2.0

  ruleStatus:

    experimental

    candidate

    validated

    stable
```

Every experiment performed by humans is stored here.

No experiment is discarded.
