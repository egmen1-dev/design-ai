# SPEC-2207 — AntiRule

AntiRule stores validated negative knowledge.

AntiRule prevents repeated failed strategies.

```yaml
AntiRule:

  id:

  statement:

  forbidden_action:

  reason:

  evidence:

  confidence:

  applies_to:

  created_from:
    - failed_experiment
    - regression
    - benchmark_negative
    - human_rejection

  lifecycle_state:
    allowed:
      - validated
      - certified
      - stable
      - deprecated
      - archived
```

Example:

```yaml
AntiRule:
  id: AR_WIDE_TEMPLATE_COMPOSITOR_HOOK
  forbidden_action: enable_wide_template_compositor_hook_in_production
  reason: Stage 5.1 reduced factual compositeProductAreaRatio from 0.20 to 0.12.
  confidence: 0.98
```
