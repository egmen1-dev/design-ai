# SPEC-2205 — Applicability

Every Genome object SHALL define applicability.

```yaml
Applicability:

  marketplaces:
    - Wildberries
    - Ozon
    - Amazon
    - Shopify

  categories:
    include: []
    exclude: []

  product_types:
    include: []
    exclude: []

  constraints:
    aspect_ratio:
      min:
      max:

    color:
      include:
      exclude:

    audience:
      include:
      exclude:
```

A rule with undefined applicability SHALL NOT be used in Production Mode.
