# SPEC-306 — Adaptive Parameter

Adaptive Parameters are runtime variables selected by Decision Engine.

Adaptive Parameters are category-dependent.

Adaptive Parameters are benchmark-driven.

```yaml
AdaptiveParameter:

  id:

  category:

  parameter:

  currentValue:

  confidence:

  source:

  benchmarkHistory:
```

## Examples

```text
Background Brightness

Scene Type

Environment

Lighting Temperature

Camera Angle

Minimalism Level

Whitespace Target

Visual Energy
```
