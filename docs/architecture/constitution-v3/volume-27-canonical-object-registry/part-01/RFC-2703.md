# RFC-2703 — Canonical Object Types

The following top-level object types are allowed.

```yaml
GenerationContext

DecisionGraph

SceneGraph

CommercialGenome

KnowledgeBundle

Metric

Event

Command

Protocol

Plugin

Node

Law

Rule

Pattern

Strategy

Benchmark

Experiment

Evidence

ResearchReport

FeatureFlag

AuditReport

LearningRecord
```

New top-level object types require an approved RFC.
