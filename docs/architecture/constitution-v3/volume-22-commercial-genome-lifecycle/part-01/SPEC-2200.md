# SPEC-2200 — Genome Lifecycle States

Every Genome object SHALL exist in exactly one lifecycle state.

```yaml
GenomeLifecycleState:

  idea:
    description: untested observation
    production_allowed: false

  hypothesis:
    description: testable commercial statement
    production_allowed: false

  experimental:
    description: tested in limited experiments
    production_allowed: false

  candidate:
    description: positive evidence exists
    production_allowed: false

  validated:
    description: benchmark and experiment support exists
    production_allowed: beta_only

  certified:
    description: production certified
    production_allowed: true

  stable:
    description: long-term production rule
    production_allowed: true

  deprecated:
    description: should not be selected for new decisions
    production_allowed: false

  archived:
    description: historical only
    production_allowed: false
```

Production Mode SHALL consume only:

```yaml
allowed_in_production:
  - certified
  - stable
```
