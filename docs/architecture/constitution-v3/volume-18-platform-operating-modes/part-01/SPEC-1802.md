# SPEC-1802 — Refinement Mode

Purpose:

Improve an existing solution.

Refinement SHALL operate under

Rule Of One Change.

Exactly one commercial parameter SHALL change per iteration.

Examples:

```yaml
Hero Scale

Lighting

Background

Headline

Badge Position

Typography

Spacing
```

Multiple simultaneous commercial changes are prohibited.

Outputs:

```yaml
RefinementDecision

DeltaBenchmark

ImprovementEvidence
```
