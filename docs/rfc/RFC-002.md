# RFC-002 — Runtime

| Field | Value |
|-------|-------|
| **RFC Number** | RFC-002 |
| **Title** | Runtime |
| **Author** | Architecture Team |
| **Status** | Accepted |

## Motivation

Production handler (`generate-infographic-handler.ts`) orchestrates all stages inline. Runtime must become the sole orchestrator per LAW and Part 12.

## Architecture

- DAG-based execution (Design Graph)
- EventBus for stage notifications
- VersionManager for state snapshots
- Platform registry for isolated platform invocation
- Failure recovery and retry at orchestration layer

## Implementation

See Part 5, Part 12, RUN-001–RUN-004. Wave 01 creates skeleton; subsequent waves register platforms.

## Migration

Handler delegates to `runDesignAiBookPipeline()` behind feature flag until Wave 10.

## Alternatives

- Keep monolithic handler (rejected)
- Microservices per platform (rejected — over-engineering for current scale)

## Compatibility

Parallel execution paths during migration.

## Risks

- Orchestration bugs during cutover
- Event ordering in distributed future

## Acceptance

Runtime is sole orchestrator for new path. No legacy imports in runtime module.
