# RFC-2203 — Genome Integrity

Commercial Genome SHALL satisfy:

```yaml
Integrity:
  every_object_has_lifecycle_state: true
  every_object_has_confidence: true
  every_object_has_evidence: true
  every_object_has_owner: true
  every_object_has_version: true
  every_production_object_has_applicability: true
```

Integrity violation SHALL fail Genome loading.
