# SPEC-605 — Decision Objects

Decision Engine produces specialized decisions.

```yaml
DecisionObjects:

  HeroDecision

  EnvironmentDecision

  SceneDecision

  CompositionDecision

  TypographyDecision

  LightingDecision

  CameraDecision

  MaterialDecision

  OverlayDecision

  MarketplaceDecision
```

DecisionGraph aggregates all Decision Objects.
