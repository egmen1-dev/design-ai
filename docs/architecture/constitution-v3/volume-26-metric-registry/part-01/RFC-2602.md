# RFC-2602 — Metric Ownership

Every metric SHALL have exactly one owner.

Examples

```yaml
ProductAreaRatio

↓

SceneGraph.Product.actual.areaRatio

Owner:
SceneGraph
```

```yaml
OverlayDensity

↓

SceneGraph.Overlay.actual.overlayDensity

Owner:
SceneGraph
```

```yaml
LAW003Score

↓

Constitution Engine

Owner:
Constitution Engine
```

Duplicate ownership is prohibited.
