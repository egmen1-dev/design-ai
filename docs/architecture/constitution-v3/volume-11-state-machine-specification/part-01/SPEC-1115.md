# SPEC-1115 — State Ownership

Every state has exactly one owner.

```text
Research

↓

Research Engine

Knowledge

↓

Knowledge Engine

Decision

↓

Decision Engine

Scene

↓

SceneGraph Builder

Execution

↓

Execution Layer

Governance

↓

Governance Engine

Benchmark

↓

Benchmark Engine

Learning

↓

Learning Engine
```

Ownership SHALL NOT overlap.
