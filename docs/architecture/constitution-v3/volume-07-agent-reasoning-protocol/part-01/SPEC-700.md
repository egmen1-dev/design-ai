# SPEC-700 — Universal Reasoning Pipeline

Every agent executes the following pipeline.

```text
Receive Context

↓

Validate Context

↓

Retrieve Knowledge

↓

Collect Evidence

↓

Identify Constraints

↓

Generate Findings

↓

Generate Proposal

↓

Estimate Impact

↓

Estimate Confidence

↓

Publish Protocol Object
```

Skipping steps is forbidden.
