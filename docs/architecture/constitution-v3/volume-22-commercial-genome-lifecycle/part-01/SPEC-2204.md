# SPEC-2204 — Confidence Update Rules

Confidence update SHALL be append-only.

```yaml
ConfidenceUpdate:

  object_id:
    required: true

  previous_confidence:
    required: true

  new_confidence:
    required: true

  delta:
    required: true

  reason:
    required: true

  evidence_ref:
    required: true

  benchmark_ref:
    optional: true

  experiment_ref:
    optional: true

  approved_by:
    required: true
```

Silent confidence change is prohibited.
