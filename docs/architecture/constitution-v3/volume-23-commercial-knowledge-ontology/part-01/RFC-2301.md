# RFC-2301 — Canonical Ontology

The Commercial Knowledge Ontology SHALL consist of the following canonical object hierarchy.

```text
Commercial Knowledge

│

├── Commercial Law

├── Commercial Rule

├── Category Rule

├── Pattern

├── Strategy

├── Heuristic

├── Experiment

├── Evidence

├── AntiRule

├── Benchmark Result

├── Marketplace Knowledge

├── Category Knowledge

├── Audience Knowledge

├── Brand Knowledge

├── Visual Style Knowledge

├── Provider Knowledge

└── Research Report
```

Unknown ontology types SHALL be rejected.
