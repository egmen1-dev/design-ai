# RFC-2201 — Genome Object Types

Commercial Genome SHALL manage the following object types:

```yaml
GenomeObjectTypes:

  CommercialLaw:
    stability: very_high
    promotion_threshold: exceptional

  CommercialRule:
    stability: high
    promotion_threshold: strict

  CategoryRule:
    stability: medium
    promotion_threshold: category_validated

  AdaptiveParameter:
    stability: dynamic
    promotion_threshold: benchmark_validated

  AntiRule:
    stability: high
    purpose: prevent_repeated_failed_strategies

  Pattern:
    stability: medium
    purpose: reusable_commercial_design_structure

  Heuristic:
    stability: low
    purpose: weak_guidance_until_validated
```

Unknown Genome object types SHALL be rejected.
