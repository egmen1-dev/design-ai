# SPEC-2208 — Versioning

Every Genome object SHALL be versioned.

```yaml
GenomeObjectVersion:

  object_id:

  version:

  previous_version:

  change_type:
    - created
    - promoted
    - confidence_updated
    - applicability_updated
    - deprecated
    - archived

  change_reason:

  evidence_refs:

  created_at:

  approved_by:
```

Deletion is prohibited.

Historical versions SHALL remain readable.
