# SPEC-203 — Hypothesis

Every experiment begins with exactly one hypothesis.

```yaml
Hypothesis:

  id:

  statement:

  assumptions:

  variables:

  expectedOutcome:

  successCriteria:

  priority:
```

## Example

```yaml
Hypothesis:

  statement:

    Increasing product dominance improves CTR.

  variables:

    productAreaRatio

  successCriteria:

    CTR increase
```
