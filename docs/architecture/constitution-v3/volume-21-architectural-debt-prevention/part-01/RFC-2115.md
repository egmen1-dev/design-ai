# RFC-2115 — Architectural Review Gate

Every Pull Request SHALL answer:

1. Can an existing subsystem perform this task?

2. Does this duplicate an existing metric?

3. Does this create another source of truth?

4. Does this introduce another bridge?

5. Can this be expressed as knowledge instead of code?

6. Can this be implemented through Plugin ABI?

7. Does this increase architectural entropy?

If any answer indicates unnecessary complexity:

Implementation SHALL be rejected.
