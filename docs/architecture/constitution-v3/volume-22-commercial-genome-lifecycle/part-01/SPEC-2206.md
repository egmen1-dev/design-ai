# SPEC-2206 — Conflict Model

Genome objects MAY conflict.

Conflicts SHALL be explicit.

```yaml
GenomeConflict:

  object_a:

  object_b:

  conflict_type:
    - semantic
    - metric
    - category
    - commercial
    - visual
    - governance

  resolution_policy:
    - higher_confidence_wins
    - higher_priority_wins
    - category_specific_wins
    - human_review_required

  resolved:
    type: boolean
```

Unresolved critical conflicts SHALL block certification.
