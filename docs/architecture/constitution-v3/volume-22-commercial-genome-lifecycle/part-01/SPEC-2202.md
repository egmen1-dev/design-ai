# SPEC-2202 — Promotion Requirements

Promotion SHALL require evidence.

```yaml
PromotionRequirements:

  hypothesis_to_experimental:
    requires:
      - experiment_definition
      - success_criteria

  experimental_to_candidate:
    requires:
      - completed_experiment
      - evidence
      - measurable_effect

  candidate_to_validated:
    requires:
      - benchmark_positive
      - no_critical_regression
      - applicability_defined

  validated_to_certified:
    requires:
      - repeated_success
      - human_approval
      - regression_suite_pass
      - conflict_review

  certified_to_stable:
    requires:
      - long_term_success
      - cross_category_review
      - no_recent_regression
```

If requirements are not met, promotion SHALL be rejected.
