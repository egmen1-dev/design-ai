# SPEC-502 — Commercial Rule

Commercial Rules operationalize Commercial Laws.

Rules are measurable.

Rules contain thresholds.

Rules evolve through benchmark validation.

## Example

```yaml
CommercialRule:

  name:

    Hero Product Area

  target:

    0.50–0.60

  benchmarkConfidence:

    0.94

  promotedFrom:

    ExperimentSeries-17
```
