# SPEC-2213 — Genome Audit

Genome audit SHALL run before Production Mode.

Audit checks:

```yaml
GenomeAudit:
  missing_confidence:
  missing_evidence:
  unresolved_conflicts:
  expired_experimental_rules:
  deprecated_rules_in_use:
  duplicate_rules:
  orphan_evidence:
```

Production SHALL NOT start if critical audit findings exist.
