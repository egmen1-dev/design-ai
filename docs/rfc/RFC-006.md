# RFC-006 — Asset Platform

| Field | Value |
|-------|-------|
| **RFC Number** | RFC-006 |
| **Title** | Asset Platform |
| **Author** | Architecture Team |
| **Status** | Accepted |

## Motivation

Assets (images, fonts, overlays, exports) need versioning, graph relationships, and lifecycle management per Part 14.

## Architecture

- Asset types and `AssetObject` contract
- Asset Graph for dependencies (product photo → background → final PNG)
- Asset Manager for storage, versioning, retrieval
- Integration with ProjectState and Runtime

## Implementation

See Part 14 AST-001, AST-002. Implement after Wave 02 (contracts) and parallel to Rendering wave where possible.

## Migration

Existing file storage paths wrapped; new assets registered in graph incrementally.

## Alternatives

- Flat file storage only (rejected — no traceability)
- External DAM integration (future)

## Compatibility

Additive asset registration; legacy URLs supported during transition.

## Risks

- Storage growth
- Graph orphan nodes

## Acceptance

Assets versioned and traceable through ProjectState. Asset graph queryable.
