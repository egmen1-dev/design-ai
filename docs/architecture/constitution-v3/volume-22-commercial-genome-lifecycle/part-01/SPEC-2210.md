# SPEC-2210 — Production Consumption

Decision Engine SHALL consume only applicable Genome objects.

Selection filter:

```yaml
ProductionGenomeFilter:

  lifecycle_state:
    allowed:
      - certified
      - stable

  applicability:
    must_match_generation_context: true

  conflicts:
    unresolved_critical_conflicts_allowed: false

  confidence:
    minimum: 0.70
```

Rules below minimum confidence SHALL be ignored in Production Mode.
